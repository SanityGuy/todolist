# To-Do List
A simple modern to-do list website that allows you to create your own to do list online with accessability on any device equipped with authentication to provide security, privacy, and reassurance that no unauthorized user can see your contents.

## Stack
- Laravel
- PHP
- Vite
- TailwindCSS
